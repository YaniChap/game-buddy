# Changelog

## 0.2.0

- Rebuilt the GameBuddy interface as a responsive dark neon-purple dashboard.
- Added six companion personalities and adjustable teasing, energy, and response length.
- Added persistent local settings and controls for Steam polling, game-session tracking, event notifications, quiet hours, spoiler policy, automatic tips, session reports, and moment retention.
- Added Steam unlink action that deletes the local bearer token and resets in-memory session state.
- Added streamer mode to hide current and recent game titles in the UI.
- Added settings-aware language, personality, and response instructions to companion prompts.
- Kept the existing Steam API and Astra tools; documented the limits of game-event data.
