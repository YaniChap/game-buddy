# GameBuddy — игровой компаньон Astra

GameBuddy связывает игровую активность Steam с диалогом Astra. Версия 0.2.0 добавляет настраиваемый характер компаньона, расширенную панель управления, управление уведомлениями и отвязку Steam.

## Возможности

- Привязка Steam одноразовым восьмизначным кодом.
- Отвязка Steam с удалением локального токена авторизации.
- Отслеживание текущей игры, игровых сессий и смены игр.
- Реакции на доступные в событиях достижения и игровые моменты.
- Инструменты Astra: `game_coach`, `current_game_session`, `record_game_moment`, `session_report`, `steam_library`, `steam_recent_games`, `steam_achievements`.
- Настраиваемая личность: дружелюбная, roast-мастер, саркастичная, тренер, хайп-комментатор и чилл.
- Регуляторы остроты подколов и энергичности.
- Настройки уведомлений, тихих часов, частоты опроса Steam, спойлеров, подсказок и отчётов.
- Неоновый тёмный интерфейс с фиолетовым акцентом.
- Русская и английская локализации.

## Настройки

Настройки GameBuddy сохраняются локально в `%LOCALAPPDATA%\GameBuddy\settings.json`. Steam-токен хранится отдельно в `%LOCALAPPDATA%\GameBuddy\steam_token.txt` и удаляется при отвязке аккаунта.

Параметры включают:

- характер Астры и интенсивность подколов;
- энергичность и подробность ответов;
- язык интерфейса;
- отслеживание сессий, запуска и завершения игр;
- реакции на достижения и автоматические советы;
- сохранение игровых моментов и отчёты;
- частоту проверки Steam;
- глобальные уведомления и тихие часы;
- спойлеры и нежелательные советы во время матча;
- онлайн-статус, компактный режим и режим стримера.

## Ограничения отслеживания

GameBuddy использует события Astra `games_changed` и `companion_game_changed`, а также периодически опрашивает сервер GameBuddy для получения текущей Steam-активности. Плагин не сканирует процессы Windows и не может достоверно определить победу, поражение или убийства, если эти данные не переданы Astra/Steam или не сообщены самим игроком. Неизвестные игровые события не должны выдаваться за факты.

Игровые сессии и записанные моменты пока находятся в памяти процесса и сбрасываются при перезапуске Astra. Настройки и Steam-токен хранятся отдельно на диске.

## Разработка и проверка

Требуются Rust toolchain и Astra CLI.

```bash
cargo fmt --check
cargo test
astra-plugin locale sync
astra-plugin check . --strict
astra-plugin test .
astra-plugin dev .
```

Перед публикацией соберите плагин для целевой платформы командой Astra CLI. Готовый исполняемый пакет должен быть пересобран из этого исходного кода: бинарный файл из предыдущей версии не содержит новых изменений.

## Разрешения Astra

- `subscribe_events` — игровые события Astra.
- `send_chat_message` — сообщения компаньона в диалог Astra.
- `push_to_ui` — обновление интерфейса.
- `client` — клиентская интеграция.
